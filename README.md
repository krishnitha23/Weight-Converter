# Python Weight Converter ⚖️

A simple Python program that converts weight between **kilograms (kg)** and **pounds (lbs)**.

## 📌 Features

- Convert kilograms to pounds
- Convert pounds to kilograms
- Takes user input through the terminal
- Displays the converted weight with 1 decimal places

## 🛠️ Technologies Used

- Python 3
